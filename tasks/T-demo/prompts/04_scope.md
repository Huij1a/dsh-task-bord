# 04 选题定位

## 任务

从 03 的方向里选定一个，把"真实决定"和"交付要求"钉死。

## 必须回答

1. **谁负责**：哪个岗位为最终判断负责？他拿成果去做什么？
2. **什么时点**：业务时间点（不是文件制作日期）。
3. **决定什么**：一句话，能说清"批不批 / 订多少 / 选谁 / 发不发 / 赔不赔"。
4. **错了损失什么**：多付钱、错过期限、放错货、错发配置、违规被罚。
5. **值不值 100 元**：这个决定如果做对，人工要花多少小时？

## 交付要求定死

| 项 | 必须写死 |
|---|---|
| 交付文件 | 文件名、格式、sheet 名/节标题 |
| 字段 | 必填字段全称 |
| 精度 | 小数位、取整规则 |
| 容差 | 数值允许误差 |
| 结论形式 | 只能从哪几个选项里选 |

## 输出

- `artifacts/04_scope/决定与交付.md`：上面五问 + 交付要求表
- `artifacts/04_scope/边界.md`：不做什么、需要哪些外部条件、哪些不许模型做

## 硬要求

- 交付要求必须具体到"sheet 叫什么、列叫什么"，否则后面 14 评分无法自动判。
- 时点写北京时间，标明是业务时点。

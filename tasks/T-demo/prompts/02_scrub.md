# 02 脱敏

## 任务

把 01 采集到的素材整理成可以进题目附件的底稿，去掉真实主体，保留业务机制。

## 规则

1. 真实主体（公司名、人名、机构名、可反向检索的标题）一律替换，但**正文、表格、跨文件引用要一致**。
2. 保留：业务关系、金额量级、时间结构、规则条款、状态机、权限关系。
3. 不保留：真实联系方式、身份证/工号、可定位到具体个人的信息、原始 URL。
4. 不得过度脱敏到丢失真实感：如果把行业术语、业务约束都删掉，这题就废了。

## 输出

- `artifacts/02_scrub/脱敏底稿.md`：每份素材的脱敏后版本
- `artifacts/02_scrub/映射表.csv`：列 `原主体,替换后,出现位置`
- `artifacts/02_scrub/脱敏检查.md`：逐份说明保留了哪些必要事实、去掉了哪些标识

## 硬要求

- 替换后的名字在全文、全表、跨文件引用中必须一致。
- 不要用"某某公司A"这种一眼假的占位名；用可信的行业命名习惯。

# 18 提交准备

## 任务

把题包内容映射到平台字段，并写清每个阶段的真实状态。

## 字段映射

| 平台字段 | 取哪里 | 注意 |
|---|---|---|
| 任务名称 | 题面标题 | 一句话说清做什么 |
| 任务类型 | 04 的决定 | 必须是规范六类之一 |
| 任务形式 | 单轮/多轮 | 多轮要说明承接关系 |
| L1/L2 行业 | 用户给的行业 | 不能跨 L1 |
| L1/L2 职业 | 04 的责任岗位 | 按职业簇，不按题目里出现的术语 |
| 题目-文字 | 08 题面 | 完整正文，不含本机路径 |
| 题目-附件 | 仅模型输入包 | 不要把专家侧文件放进去 |
| 考点 | 11 考点 | 按平台要求的格式 |
| 作答思路 | 05+11 | 专家合理完成路径，不含内部工具日志 |
| 标准答案-文字 | 11 标答结论 | 本版结论，不是旧版 |
| 标准答案-附件 | 11 的 B 系列 | 与实际交付物对应 |

## 阶段状态

分开写：材料制作 / 内容核验 / 附件制造 / 独立作答 / 评分 / 质检 / 打包 / 平台保存 / 上传 / 提交 / 审核。

**每一阶段只写有回执的**。本地做完不等于平台通过。

## 输出

- `artifacts/18_submit/字段映射.md`
- `artifacts/18_submit/状态.md`
- `artifacts/18_submit/待办.md`

## 硬要求

- 不伪造模型分数、运行时间、AI 率、审核结果
- 未做的阶段写"未做"，不写"待确认"

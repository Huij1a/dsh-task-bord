# 10 难度诊断（判定节点）

## 任务

判定这套题够不够难。**只出结论，不改任何文件。**

## 判据（逐项）

| # | 判据 | 不通过条件 |
|---|---|---|
| 1 | 难点覆盖 | 难点清单少于 8 条，或有一类完全没覆盖 |
| 2 | 考点可追溯 | 有条目在考点里找不到对应难点 |
| 3 | 送分占比 | 格式/结构/常规计算/常识类考点超过总分 30% |
| 4 | 附件纠缠 | 抽走任一附件，没有任何判断受影响 |
| 5 | 链路 | 任务能被一步或两步完成，没有必须顺序执行的多阶段 |
| 6 | 必经工作量 | 不是逐笔/逐户/逐 SKU 处理，或汇总不需要对回明细 |
| 7 | 判断标准自推 | 题面直接告诉了该看哪个指标 |
| 8 | 无解/反例 | 没有任何"正确答案是不能继续"或"看着有问题其实没问题"的设计 |
| 9 | 关键数字唯一 | 核心结果存在多个合法答案却没给判定口径 |

## 输出

`artifacts/10_difficulty/诊断.md`：

```
结论：通过 / 不通过
逐项：1 ✅ 2 ❌（原因）…
返修建议：回哪个节点改什么（具体到附件/字段/段落）
```

## 返修路由

- 1、4、5、6 不过 → 回 05 改难点与附件
- 2、3、9 不过 → 回 11 改考点（如果 11 已有）或回 05
- 7、8 不过 → 回 08 改题面

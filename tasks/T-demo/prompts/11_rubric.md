# 11 考点与标答

## 任务

产出两样东西：可执行的考点文件、独立算出的标准答案。

## 一、考点（rubric.json）

```json
{"meta": {"total": 100, "items": 60, "strategy": "fixed"},
 "items": [
   {"id": 1, "score": 2, "kind": "cell|summary|derived|manual",
    "where": {"sheet": "决策摘要", "key": "案件总数", "col": 2, "cell": "B2"},
    "expect": 2400, "tol": 0, "unit": "单",
    "text": "案件总数为2,400单，允许误差0单"}
 ]}
```

规则：
- 一条只查一件事
- 数值必须带单位和容差
- 分值合计 = 100
- 能唯一确定的写成具体数；开放部分写"必须含哪些点、不能出现哪些错"
- 每条能追溯到 05 的某个难点

## 二、标准答案

从**模型能看到的材料**独立算，分四层：
1. 事实取值（哪份附件哪个字段）
2. 计算与筛选（口径、公式、范围）
3. 业务决定（结论与允许分支）
4. 执行与交接（谁做什么、什么时点）

## 三、反事实检查

只在副本里改一个声明为可编辑的参数，给出预期变化，验证标答是活的而不是抄的。

## 输出

- `artifacts/11_rubric/rubric.json`
- `artifacts/11_rubric/答案核验.md`：四层追溯 + 反事实结果
- `artifacts/11_rubric/B*.xlsx`：标答文件（结构与 04 要求一致）
- `artifacts/11_rubric/易错点.md`：核对时照着看的错法清单

## 硬要求

- 标答不能引用教师私有笔记里的条件
- 同一答案键换个脚本再算一遍，不算独立复算
- 条件必须约束到实际明细/数字/决定，不能只写在正文里

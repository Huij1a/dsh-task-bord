# 08 题面

## 任务

写题目正文（prompt）。只写委托，不写解法。

## 结构（R-T-C-O-F）

| 要素 | 必须写 |
|---|---|
| R 角色 | 你是谁、什么岗位、向谁负责 |
| T 任务 | 现在要决定什么、交付什么 |
| C 上下文 | 业务时点、为什么现在做、附件是哪些、约束是什么 |
| O 输出 | 文件名、sheet/节、字段、精度、容差 |
| F 约束 | 不许做什么（不许外部检索、不许调用外部扫描器、状态标记规则） |

## 必须写进去的

- 五个业务截止时点及其含义（如果题涉及时点重放）
- 处理顺序（如果规则有优先级）
- 硬边界：资金上限、日期上限、库存/产能上限
- 状态标记规则（未发生的动作写"待执行"）
- 交付物清单，文件名与 04 一致

## 绝对不能写进去的

- 具体金额答案、正确分类数量
- 先看哪张表、按什么顺序筛、怎么去重
- "注意不要…""容易出错的是…"
- 考点编号、评分标准

## 输出

- `artifacts/08_prompt/题面.md`
- `artifacts/08_prompt/字段映射.md`：题面要求 ↔ 交付物字段对照

## 自检

- [ ] 一个刚入行的同事看完，知道第一步做什么、最后交什么
- [ ] 所有数值边界都写死了（含/不含、上限/下限）
- [ ] 没有一句话在暗示解题路径
- [ ] 交付文件名与 04 完全一致

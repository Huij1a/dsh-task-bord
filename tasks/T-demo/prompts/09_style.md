# 09 润色

## 任务

把题面和附件里的文字改成岗位上真实会写的样子，**只改表达，不改事实**。

## 文种差异

- 邮件/交班：像同事当时发的，写当下知道的事和要办的事
- 工单：保留顾客原话、客服记录、处理状态
- 制度/合同：保留正式程度和条款结构
- 台账：字段准确，不要写成小作文

## 必须保持

金额、日期、编号、对象、状态、条件、否定、承诺、权限。

## 典型改法

| 别这样写 | 改成 |
|---|---|
| 核明对应层级并完成闭合 | 把这个付款单号和这批订单对一下，确认后回给财务 |
| 统一退款口径 | 确认这批退货款怎么算，原付款失败后由谁补办 |
| 库存待核 | 返厂批次已签发，WMS 尚未过账 |

## 不要做

- 不要批量替换词语后直接交（"核明"换成"核实"不算改完）
- 不要制造错别字、乱排版来"去 AI 味"
- 不要把专业词一律口语化（核销、过账、适用范围该留就留）

## 输出

- `artifacts/09_style/润色说明.md`：逐处列 改前 → 改后 → 保真项
- 直接改 `artifacts/08_prompt/题面.md` 和 `artifacts/06_wps/` 里的文书类附件

## 自检

- [ ] 数字、时间、对象、条件、否定、承诺没变
- [ ] 不同文种读起来不一样
- [ ] 没有一句像考题讲解

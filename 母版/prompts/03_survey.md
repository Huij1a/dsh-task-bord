# 03 材料初勘

## 前置读取

先读取 `artifacts/00_spec/项目门槛.json`、`artifacts/00_spec/规范摘录.md`、`artifacts/02_scrub/脱敏底稿.md` 及其列出的 `artifacts/02_scrub/脱敏底稿/<SID>.md`：

- 材料必须属于 `args.industry`；`industry_tree` 非 `null` 时，只使用对应路径下的材料，`null` 时记录“规范未声明行业树”，不得自行补层级。
- 候选方向只能落在 `task_types` 规定的题型内；`task_types` 为 `null` 且选题必须依赖它时，停止并回报“规范未定义题型”，不得自行补全。
- `forbidden` 中的对象、做法、字段或表述不得成为方向。
- 下游需要行业、业务语义或时间口径时，只能引用门槛或规范摘录里有原文来源的值；平台投稿栏位不是题目业务字段。

## 任务

判断这批材料能出什么题，列出实质不同的可选方向，并说明每个方向的材料缺口。

## 方法

对每份底稿回答：
1. 这份材料主张什么、用了什么方法、适用什么条件；
2. 现实中的谁，会拿它做什么决定；
3. 这个决定还依赖哪些**材料里没有**的业务事实。

### 方向量化口径

对每个方向分别把 `证据可得性`、`业务价值`、`可判定性`、`预估工作量`、`推荐度` 评为 0–3 的整数；不得用小数、空值或“较高/较低”等不可复核词代替：

- `0`：没有可用证据、没有实质业务价值、无法形成可判定结果，或工作量明显不可承受。
- `1`：只有弱证据、价值或可判定性有限，或工作量偏大但仍有可行路径。
- `2`：有可定位的直接证据，能够支撑真实决策和独立判定，工作量可控。
- `3`：有直接且可复核的原文证据，决策价值、可判定性和材料承载均最强，工作量在当期条件下稳定可控。

`证据可得性` 评 0 表示没有实际 `source_id` 和底稿定位，`可判定性` 评 0 表示无法形成可独立核对的交付结果；二者任一为 0 的方向不得进入候选。`推荐度` 只用于同批方向排序，不得覆盖评测维度，也不得作为通过门槛；04 必须引用被选中的 `DIRxx` 和逐项淘汰理由。所有评分必须能在 `可用方向.md` 或评估 CSV 的证据定位中复核。

## 为什么不能直接出题

复盘类材料通常只给结论，不给逐笔明细、回执、状态流转。直接拿它出题会变成“阅读理解”。

## 输出

以下两件都是必需产物，路径和文件名不得改：

- `artifacts/03_survey/可用方向.md`：每个方向写
  - 稳定方向 ID `DIR01`、`DIR02`…（本题生命周期内唯一且不复用）
  - 方向名
  - 对应 `task_types` 及依据
  - 真实决定（谁、在什么时点、决定什么、错了会损失什么）
  - 现有材料能支持什么非空 `source_ids`
  - 还缺什么（要自己构造的业务记录）
  - 难度来源（多阶段链路/附件纠缠/隐性规则/必经工作量/规则组合/标准自推）
  - 实际证据定位（`source_id` + 底稿文件 + 可复核段落/单元格/页锚点）
- `artifacts/03_survey/方向评估.csv`：列 `direction_id,方向,任务类型,source_ids,证据定位,证据可得性,业务价值,可判定性,预估工作量,推荐度`；最后五列均必须是 0–3 的整数

## 硬要求

- 方向数量由材料能支撑的实质方案决定，不得为凑数硬拆；方向太少不足以形成真实选择时，报告材料缺口并退回 01。
- 每个入候选的方向必须至少有一个真实 `source_id` 和底稿定位；缺失或无法复核的方向是硬失败，不得用价值评分或推荐度补偿。
- 覆盖当前规范允许的不同拆法（业务场景、工作任务、分析视角、客户类型、精准考点），每一条都要说明取自哪份 `source_id` 与实际底稿定位。
- 选择顺序固定为：先过“证据可得性>0 且可判定性>0”的硬门，再按实际证据质量、业务价值和材料承载比较；推荐度只作同批排序，不得写死具体阈值或预设方向类型。
- 不要把所有方向都写成同一种结构，也不得把其他行业或其他期次的题型当默认候选。
